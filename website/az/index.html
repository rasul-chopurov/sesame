Laravel icması üçün nativ, süni intellektə uyğun server meneceri. SSH verin — bütün saytları, bazaları, poçtu və prosesləri tapır və onları sizinlə birlikdə idarə edir.

Nə edir

Serverdəki hər şey bir sakit pəncərədə.

Sesame serverinizi sizin kimi oxuyur — SSH ilə, əvvəlcə yalnız oxuma rejimində — və tapdıqlarını idarə edilə bilən bir mənzərəyə çevirir.

Kəşf

Həqiqətən nə işlədiyini görün

Bir oxuma yoxlaması FrankenPHP/Caddy, Nginx və Apache-dəki saytları, Laravel tətbiqlərini və onların .env drayverlərini, supervisor proseslərini, bazaları, cron-u, sertifikatları və firewall-u tapır — və nəyin diqqət tələb etdiyini göstərir.

  • FrankenPHP
  • Octane
  • Nginx
  • MySQL
  • PostgreSQL
  • Redis
  • cron
  • ufw
İzolə edilmiş saytlar

Yeni sayt, tam ayrılmış

Hər sayt öz Linux istifadəçisini, öz PHP-FPM pulunu və ya Octane-ı, öz baza istifadəçisini və Redis ACL-ni alır. Veb server yalnız public/ qovluğunu oxuyur — .env faylınızı heç vaxt.

  • öz istifadəçi
  • öz pul
  • öz baza
  • Redis ACL
Xidmətlər

Bazalar bir kliklə

Redis, PostgreSQL, MariaDB, MongoDB, Elasticsearch, RustFS üzərində S3 və Reverb — yalnız localhost-da, yaradılmış parollarla. Siz istəməyincə heç nə quraşdırılmır.

  • yalnız localhost
  • silərkən məlumat qalır
Deploylar

GitHub-a push, Sesame-də deploy

Saytı repozitoriya və budaqla əlaqələndirin. Sesame serverdə yalnız oxuma üçün deploy açarı yaradır, sonra kodu çəkir, asılılıqları quraşdırır, miqrasiyaları işə salır və prosesləri yenidən başladır.

  • deploy açarları
  • miqrasiyalar
  • workerlər
Cloudflare

Tablar arasında keçid olmadan DNS

Domenlər, qeydlər, proksi aç/bağla, keşin təmizlənməsi — və hələ serverə yönəlməmiş hər sayt üçün «bu serverə yönəlt» düyməsi.

  • DNS qeydləri
  • proksi
  • keş
Təhlükəsiz dizayn

Hər dəyişiklik baş verməzdən əvvəl göstərilir.

Sesame serveri xəbəriniz olmadan dəyişmir. Planlar əvvəlcədən göstərilir, geri qaytarılmaz addımlar adı yazmağınızı tələb edir və hər şey audit jurnalına düşür.

Əvvəlcə yalnız oxuma

Kəşf heç nə yazmır. .env-dən parol və açarları da oxumur.

Şifrəli anbar

Sirlər master paroldan Argon2id ilə alınan açarla XChaCha20-Poly1305 vasitəsilə şifrələnir.

Təsdiqlə, sonra icra et

Hər plan addımlarını göstərir. Silmədən əvvəl ehtiyat nüsxə çıxarılır və adı yazmaq lazımdır.

Komanda sətrindən kənarda

Parollar stdin və heredoc ilə ötürülür — heç vaxt argv-də, heç vaxt ps-də görünmür.

Süni intellektə uyğun

Hər əməliyyat tipli əməliyyatdır.

Tətbiq və sesame CLI eyni planları icra edir — skriptlər və süni intellekt agentləri də sizin etdiyinizi edə bilər, eyni ön baxış və eyni audit jurnalı ilə. Növbəti addım MCP və REST-dir.

# serveri yadda saxla və yoxla
$ sesame add prod root@203.0.113.10
$ sesame discover prod

# PostgreSQL ilə izolə edilmiş Laravel saytı
$ sesame do prod new-site shop.example.com --db postgres --yes

# Redis, yalnız localhost-da, parol yaradılır
$ sesame do prod install redis --yes

Nativ və sürətli

Rust və GPUI. Electron yox, JVM yox — dərhal açılır və yüngül qalır.
